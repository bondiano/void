# ADR-0002: Late binding через символы для handlers, jobs и policies

- Статус: accepted
- Дата: 2026-08-25
- Связанные разделы SPEC: §2.3, §4, Часть II §2.2

## Контекст и постановка проблемы

REPL-driven development — first-class режим фреймворка: изменение функции в REPL должно немедленно отражаться в работающей системе. Если route table, jobs и policies хранят ссылки на функции (closures), то после переопределения функции в REPL старые ссылки продолжают указывать на прежнюю версию — hot reload ломается.

## Драйверы решения

- Живость REPL: переопределил функцию — следующий запрос исполняет новую версию, без пересборки таблиц.
- `system/restart` должен требоваться только для stateful-компонентов, не для смены кода.
- Инспектируемость: в route table виден символ `'my-app.orders/show`, а не `<function 0x...>`.
- Hot path не должен платить за резолв на каждый вызов.

## Рассмотренные варианты

1. **Символы + resolve в момент вызова** с кэшем, инвалидируемым по env-generation.
2. **Прямые ссылки на функции** — быстрее, но убивает hot reload; смена кода требует полной пересборки таблиц.
3. **Var-indirection везде** (Clojure-style) — в Janet нет полноценного аналога var, эмулировать дороже, чем использовать env tables + `resolve`, которые язык даёт из коробки.

## Решение

Вариант 1: **регистрация символами, резолв при вызове**. Janet даёт для этого нативный механизм: env tables + `resolve` + late binding.

- `:handler` в route entry — символ; function-literal допустим (тесты), но помечается `:no-reload`.
- Резолв идёт через кэш с инвалидацией по env-generation — на hot path это table lookup, не полный resolve.
- Тот же принцип для `defjob`, `defpolicy`, CLI-команд.
- File watcher в dev перезагружает затронутые env tables; `system/restart` нужен только для stateful-компонентов (карта file→component из manifests).

## Последствия

Плюсы:

- Изменение кода в REPL живое сразу; dev-цикл — секунды.
- Route table и jobs-декларации сериализуемы и диффабельны (символы — данные).
- Ошибка «missing symbol» ловится на старте валидацией route table (fail fast), а не 500-кой в проде.

Минусы / цена:

- Кэш резолва и инвалидация по env-generation — дополнительная механика в ядре, которую нужно сделать корректной один раз.
- Непрямота: стек вызова содержит слой резолва; `explain-route` обязан показывать, куда символ резолвится сейчас.
- Function-literals становятся «второсортными» (`:no-reload`) — надо документировать.
