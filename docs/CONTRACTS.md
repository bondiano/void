This is the normative registry of the two contracts frozen at v0.1
(SPEC part II): the **extension points** with their contribution
schemas, and the **route metadata keys**. From this tag on, every
change follows the deprecation procedure in
[CONTRIBUTING.md](../CONTRIBUTING.md#deprecation): schemas may only
gain `:optional` fields; a rename or tightening is a **new** point or
key plus a deprecation alias for the old name, never a mutation.

## Route metadata keys

`:name` is the one bare key (required, globally unique). Every
other key is namespaced and must be declared through
`:void.http/route-meta-key` — an undeclared key is a boot error
with did-you-mean. Merge strategies (route ← group ← global):
`:replace` (specific layer wins), `:concat`, `:deep-merge`,
`:restrict` (a specific layer may only tighten; violation is a boot
error). `(http/explain-route path)` prints every value's origin by
layer.
